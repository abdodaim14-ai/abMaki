# AI Design Studio — Starter

نسخة أولية قابلة للتشغيل محلياً، بواجهة عربية RTL.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث.
3. ارفع شعارك وخطوطك وابدأ تجربة المحرر.

## الموجود في النسخة الأولى
- واجهة استوديو متعددة الأقسام.
- محرر Canvas لإضافة النصوص والأشكال والصور وتحريكها.
- تغيير مقاسات اللوحة وتصدير PNG.
- رفع اللوجو واستخراج لوحة ألوان تقريبية محلياً.
- رفع خطوط TTF/OTF/WOFF ومعاينتها واستخدامها في النصوص.
- اقتراح خطة تصميم أولية محلية.

## ما لم يتم ربطه بعد
- Gemini API الحقيقي.
- توليد الصور بالذكاء الاصطناعي.
- حفظ المشاريع في حساب المستخدم وقاعدة البيانات.
- محرر طبقات متقدم مع تدوير/قص/شفافية وتراجع/إعادة.

## الخطوة التالية: ربط Gemini بأمان
لا تضع مفتاح Gemini في `app.js` أو أي ملف يصل للمتصفح. أنشئ خادماً أو Supabase Edge Function يستقبل وصف التصميم والهوية البصرية، ويقرأ المفتاح من Secrets ثم يستدعي Gemini. بعد ذلك نستبدل التوصيات المحلية في `app.js` باستدعاء نقطة النهاية الآمنة.

## ملاحظة
استخراج الألوان في هذه النسخة تقريبي ويعمل على المتصفح. لا يتم رفع الصور إلى أي خادم في هذه النسخة.
